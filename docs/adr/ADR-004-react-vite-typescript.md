React + Vite + TypeScript

Рішення: frontend реалізується з використанням React, TypeScript та Vite.

Обгрунтування:
- React підходить для компонентного UI;
- TypeScript забезпечує типізацію frontend-коду;
- Vite має просту інтеграцію з TypeScript;
- Vite забезпечує швидкий development server;
- технології добре відповідають JavaScript/Node.js стеку;
- frontend може взаємодіяти з NestJS через REST API.
