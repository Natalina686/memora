PostgreSQL як основа СУБД

Рішення: для зберігання структурованих даних Memora використовується PostgreSQL.

Обгрунтування:

- реляційна модель добре відповідає звязкам між Account, Learner, Knowledge, Question, QuizSession тощо.
- підтримка транзакцій забезпечує цілісність даних;
- JSONB дозволяє зберігати гнучкі АІ-структури;
- PostgreSQL добре інтегрується з Prisma;
- база легко запускається в Docker;
- СУБД придатна як для MVP, так і для подальшого масштабування.
